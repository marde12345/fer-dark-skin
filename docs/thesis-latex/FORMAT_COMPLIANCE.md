## Fixed and Verified During the 2026-10-13 Compile-and-Inspect Pass

These were genuinely broken, found only by actually compiling and visually reading the PDF (a static source review could not have caught either):

1. **Bold/italic text was not rendering distinctly anywhere in the document.** Root cause: `itb-thesis.sty`'s `fontspec` configuration explicitly set `UprightFont=*, BoldFont=*, ItalicFont=*, BoldItalicFont=*`, which collapses all four shapes onto the same Regular glyph file. Every chapter title, section heading, and `apalike`-italicized bibliography journal title rendered in plain weight. **Fixed** by removing those four options and letting `fontspec` auto-detect Times New Roman's own registered Bold/Italic/Bold Italic sub-faces — **re-verified by a second compile**: the font-instance trace in the log now shows three genuinely distinct variants (`/b/n/`, `/m/it/`, `/m/n/`) instead of one identical tag everywhere, and the compiled PDF visibly shows bold chapter/section headings and italicized bibliography journal titles.
2. **4 overfull hboxes**, the two worst ~95pt (≈3.35cm) and ~83pt (≈2.9cm) past the text-block edge. Causes and fixes: (a)/(b) long unbreakable file paths (`reports/arcface_evaluation/{comparison_metrics,statistical_tests}.csv` in a Table IV.1 caption and its List-of-Tables entry; `notebooks/preprocessing_experiment.ipynb` in Chapter III body text) — fixed by inserting `\allowbreak` after path separators, no wording changed; (c) `frontmatter/abbreviations.tex`'s table, too wide for the 4cm/3cm margins — fixed by narrowing the `Nama` column from `p{9cm}` to `p{7cm}` and converting the rightmost column from unwrapped `r` to `p{3cm}`. **Re-verified by a second compile: 0 overfull hboxes remain.**

## Known Gaps (Not Silently Resolved)

1. **Widow/orphan control** for paragraphs is not explicitly configured beyond LaTeX defaults — not checked for visible widow/orphan lines across all 41 pages in this pass.
2. **The official ITB-SPs CSL** was not fetched (no network access); `apalike` is a documented substitute, and it visibly renders "et al." rather than the guide's Indonesian "dkk." in the compiled bibliography.
3. **Font availability on any machine other than the one used for this pass** remains unverified — Times New Roman is confirmed present and loading correctly *here*, but that says nothing about any other compiling machine.
4. **This guide and its matching .docx are dated 2017/2019** and were the documents supplied for this task; neither was cross-checked against any more recent or Smart-System-program-specific requirement, because none was found in this repository.
5. **Supervisor names, dates, NIM, and the final thesis title** remain `\TODO{}` placeholders in the compiled PDF (by design — nothing was invented).
6. **One trivial overfull hbox (3.18pt ≈ 1.1mm) remains** in `frontmatter/pengesahan.tex`'s two-Anggota signature-block table, introduced when it was widened from one to two member-supervisor columns to match the .docx's actual main-body example. Reducing the rule width from 5cm to 4.5cm per column did not eliminate it, and the true cause appears to be table padding/centering overhead rather than the rule width itself. Left as-is: at this magnitude it is not visible in the rendered PDF and further iteration was not a good use of effort relative to its impact.
